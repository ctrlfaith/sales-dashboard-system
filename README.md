# 📊 Sales Dashboard System  

**Sales Dashboard System** เป็นโปรเจกต์ทดลองที่ทำขึ้นเพื่อฝึกการพัฒนาเว็บระบบจัดการข้อมูลการขาย  
โดยมีจุดประสงค์เพื่อเรียนรู้การเชื่อมต่อข้อมูลจากฐานข้อมูล MySQL และนำข้อมูลไปแสดงผลในรูปแบบ Dashboard  

ระบบนี้สามารถบันทึก ดู และวิเคราะห์ยอดขายได้แบบเรียลไทม์  
โดยเชื่อมต่อข้อมูลจาก **phpMyAdmin → Google Sheets → Looker Studio**  
ก่อนนำ Dashboard ที่สร้างได้มาฝัง (Embed) ไว้ในหน้าเว็บด้วย **iframe**  

---

## ⚙️ เทคโนโลยีที่ใช้ (Tech Stack)  

- **Frontend:** HTML, CSS (Custom Styling), JavaScript  
- **Styling Framework:** Bootstrap, Google Fonts (Roboto), Bootstrap Icons  
- **Backend:** PHP (Procedural)  
- **Database:** MySQL (phpMyAdmin)  
- **Data Visualization:** Looker Studio (Embed via iframe), Google Sheets (Data Import)  

---

## 🎯 จุดประสงค์ของโปรเจกต์  
- เพื่อฝึกพัฒนาเว็บระบบจัดการข้อมูลพื้นฐานด้วย PHP และ MySQL  
- เพื่อเรียนรู้การนำข้อมูลจากฐานข้อมูลไปเชื่อมต่อกับ Looker Studio  
- เพื่อทดลองสร้าง Dashboard แบบ Interactive ที่แสดงผลได้แบบเรียลไทม์
